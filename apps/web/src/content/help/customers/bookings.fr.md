# Réserver une table ou un service dans un lieu

Certains lieux acceptent des **demandes de réservation** via Abonten. Une réservation est une demande adressée à l'établissement, pas une réservation payée : Abonten n'encaisse aucun paiement pour les réservations.

## Envoyer une demande

1. Ouvrez la page du lieu et choisissez **Demander une réservation**.
2. Choisissez un service (si le lieu en propose), la date et l'heure, le nombre de personnes, et ajoutez une note.
3. Envoyez. Le propriétaire est prévenu dans l'application.

## La suite

| Statut | Signification |
|---|---|
| En attente | En attente de réponse du propriétaire |
| Acceptée | Le propriétaire l'a confirmée |
| Refusée | Le propriétaire n'a pas pu l'accepter |
| Annulée | Vous l'avez annulée |

Vous êtes prévenu quand le propriétaire répond. Retrouvez vos réservations dans l'onglet **Réservations** de votre profil (site web : `/user/<votre nom d'utilisateur>/bookings`) ou dans **Compte › Réservations** dans l'application ; elles ne sont visibles que par vous.

## Annuler une demande

Ouvrez la réservation et choisissez **Annuler**. Vous pouvez annuler une réservation en attente ou acceptée ; faites-le le plus tôt possible pour que le lieu puisse s'organiser.

## Échanger avec le lieu

Utilisez **Message** sur la page du lieu pour poser une question avant ou après la réservation. Vous pouvez aussi appeler le lieu ou lui écrire sur WhatsApp s'il indique un numéro ; cela se passe en dehors d'Abonten.
