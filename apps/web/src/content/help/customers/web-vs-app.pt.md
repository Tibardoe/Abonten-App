# Website ou aplicação

| Funcionalidade | Website | Aplicação Android |
|---|---|---|
| Explorar, pesquisar, mapa, páginas de eventos e locais | ✓ | ✓ |
| Comprar bilhetes, inscrever-se, códigos promocionais, carteira | ✓ | ✓ |
| Bilhetes com código QR, PDF e recibo | ✓ | ✓ |
| Reservas, avaliações, destaques, favoritos | ✓ | ✓ |
| Mensagens (texto, fotografias, ficheiros) | ✓ | ✓ |
| Mensagens de voz | — | ✓ |
| Spotlight, Stories e seguir | ✓ | ✓ |
| Abonten Weekly | ✓ | ✓ |
| Notificações push | ✓ (se o navegador o permitir) | ✓ |
| Lembretes de eventos | — | ✓ |
| Ferramentas de organizador (criar, editar, códigos promocionais, finanças, levantamentos) | ✓ | ✓ |
| Registar a entrada de participantes a partir da lista | ✓ | ✓ |
| Ler os códigos QR dos bilhetes com a câmara | — | ✓ |
| Ferramentas para proprietários de locais (editar, fotografias, horário, reservas, avaliações) | ✓ | ✓ |
| Ferramentas das equipas de campo do Abonten | ✓ | — |
| Definições: perfil, segurança, idioma, aparência, eliminar a conta | ✓ | ✓ |
| Páginas legais e este centro de ajuda | ✓ | abre o website |

**iPhone:** ainda não existe uma versão da aplicação para iOS. No iPhone, pode usar o website.

**Ligações:** as ligações de eventos, locais e convites (`abontenhub.com/events/…`, `/places/…`, `/invite/…`) abrem diretamente na aplicação no Android, se estiver instalada.
