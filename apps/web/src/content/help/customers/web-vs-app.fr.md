# Site web ou application

| Fonctionnalité | Site web | Application Android |
|---|---|---|
| Parcourir, rechercher, carte, pages d'événements et de lieux | ✓ | ✓ |
| Acheter des billets, s'inscrire, codes promo, portefeuille | ✓ | ✓ |
| Billets avec QR code, PDF et reçu | ✓ | ✓ |
| Réservations, avis, temps forts, favoris | ✓ | ✓ |
| Messagerie (texte, photos, fichiers) | ✓ | ✓ |
| Messages vocaux | — | ✓ |
| Spotlight, Stories et abonnements | ✓ | ✓ |
| Abonten Weekly | ✓ | ✓ |
| Notifications push | ✓ (si le navigateur le permet) | ✓ |
| Rappels d'événement | — | ✓ |
| Outils d'organisateur (créer, modifier, codes promo, finances, versements) | ✓ | ✓ |
| Enregistrer les participants depuis la liste | ✓ | ✓ |
| Scanner les QR codes des billets avec l'appareil photo | — | ✓ |
| Outils des propriétaires de lieux (modifier, photos, horaires, réservations, avis) | ✓ | ✓ |
| Outils des équipes de terrain Abonten | ✓ | — |
| Paramètres : profil, sécurité, langue, apparence, suppression du compte | ✓ | ✓ |
| Pages juridiques et ce centre d'aide | ✓ | ouvre le site web |

**iPhone :** une version iOS de l'application n'est pas encore disponible. Sur iPhone, utilisez le site web.

**Liens :** les liens d'événements, de lieux et d'invitation (`abontenhub.com/events/…`, `/places/…`, `/invite/…`) s'ouvrent directement dans l'application sur Android quand elle est installée.
