# Paiements et moyens de paiement

Les paiements sur Abonten sont traités par **Paystack**. Les prix sont en cedis ghanéens.

## Moyens de payer

- **Carte** : saisissez votre carte dans la fenêtre sécurisée de Paystack. Abonten ne voit jamais le numéro complet de votre carte ni votre code PIN.
- **Mobile money** : choisissez votre réseau et votre numéro. Selon le réseau, vous validez une demande sur votre téléphone ou vous saisissez un code à usage unique dans l'application.
- **Moyen enregistré** : choisissez une carte ou un portefeuille enregistré auparavant et payez en une étape.

## Votre portefeuille (moyens de paiement enregistrés)

**Site web :** menu latéral › Portefeuille. **Application :** Compte › Portefeuille.

- **Ajouter une carte.** Paystack vérifie la carte avec un **débit de 1,00 GHS remboursé immédiatement** et donne à Abonten une référence réutilisable. Abonten ne conserve que cette référence, ainsi que la marque, les quatre derniers chiffres et la date d'expiration pour que vous reconnaissiez la carte.
- **Ajouter un portefeuille mobile money.** Il est enregistré sous forme d'informations d'affichage (réseau, numéro, libellé). Vous confirmez toujours chaque paiement sur votre téléphone.
- Définissez un moyen **par défaut**, ou **retirez** un moyen à tout moment. Retirer un moyen n'a aucun effet sur les paiements ni les remboursements passés.

Votre portefeuille est distinct du paiement : vous pouvez gérer vos moyens de paiement sans rien avoir dans votre panier.

## Historique des transactions

**Site web :** menu latéral › Transactions. **Application :** Compte › Transactions.

La vue d'ensemble affiche les totaux de la période choisie (total, réussies, en attente, en échec, billets achetés, montant dépensé). L'historique liste chaque achat de billets avec son statut ; ouvrez-en un pour voir le prix des billets, les frais de service et le total payé, la référence du paiement et l'état du remboursement.

Statuts que vous pouvez voir :

| Statut | Signification |
|---|---|
| En attente | Paiement commencé, pas encore réglé |
| Réussi | Payé, billets émis |
| Échec | Paiement refusé ou abandonné |
| Remboursement en attente | Un remboursement a été demandé à Paystack |
| Remboursé | Paystack a confirmé le remboursement |

## Reçus

Un e-mail de confirmation contenant vos billets est envoyé quand un achat est terminé (si votre compte a une adresse e-mail). Vous pouvez aussi télécharger ou partager un billet en PDF depuis le billet lui-même.

## Problèmes

- **Débité mais pas de billet** : voir [Acheter des billets](/help/customers/tickets-and-checkout) (« Quand le paiement prend un moment »). Utilisez Réessayer, puis contactez l'assistance si le billet manque toujours ; indiquez l'heure et le montant.
- **Débité deux fois** : Abonten empêche les doubles débits pour un même paiement. Si votre relevé montre deux débits, l'un est généralement une autorisation en attente qui disparaîtra ; si les deux sont réellement prélevés, contactez l'assistance avec les deux références.
- **Vérification de carte de 1,00 GHS non remboursée** : Paystack l'annule immédiatement, mais certaines banques l'affichent quelques jours avant qu'elle disparaisse.
