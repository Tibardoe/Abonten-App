# Website oder App

| Funktion | Website | Android-App |
|---|---|---|
| Stöbern, Suche, Karte, Event- und Ortsseiten | ✓ | ✓ |
| Tickets kaufen, anmelden, Promo-Codes, Wallet | ✓ | ✓ |
| Tickets mit QR-Code, PDF und Beleg | ✓ | ✓ |
| Buchungen, Bewertungen, Highlights, Favoriten | ✓ | ✓ |
| Nachrichten (Text, Fotos, Dateien) | ✓ | ✓ |
| Sprachnachrichten | — | ✓ |
| Spotlight, Stories und Folgen | ✓ | ✓ |
| Abonten Weekly | ✓ | ✓ |
| Push-Benachrichtigungen | ✓ (wenn der Browser es unterstützt) | ✓ |
| Event-Erinnerungen | — | ✓ |
| Veranstalter-Werkzeuge (erstellen, bearbeiten, Promo-Codes, Finanzen, Auszahlungen) | ✓ | ✓ |
| Teilnehmer über die Liste einchecken | ✓ | ✓ |
| Ticket-QR-Codes mit der Kamera scannen | — | ✓ |
| Werkzeuge für Inhaber von Orten (bearbeiten, Fotos, Öffnungszeiten, Buchungen, Bewertungen) | ✓ | ✓ |
| Werkzeuge für Abonten-Außendienstteams | ✓ | — |
| Einstellungen: Profil, Sicherheit, Sprache, Erscheinungsbild, Konto löschen | ✓ | ✓ |
| Rechtliche Seiten und dieses Hilfe-Center | ✓ | öffnet die Website |

**iPhone:** Eine iOS-Version der App gibt es noch nicht. Auf dem iPhone kannst du die Website nutzen.

**Links:** Event-, Orts- und Einladungslinks (`abontenhub.com/events/…`, `/places/…`, `/invite/…`) öffnen sich auf Android direkt in der App, wenn sie installiert ist.
