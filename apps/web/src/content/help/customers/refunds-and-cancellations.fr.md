# Remboursements et annulations

## Annuler un billet que vous avez acheté

Ouvrez le billet dans Mes billets (Gérer › Mes billets sur le site web, Compte › Mes billets dans l'application) et choisissez **Annuler le billet** tant qu'il est encore *Actif*. L'annulation libère le billet pour que quelqu'un d'autre puisse l'acheter.

## Ce qui vous est rendu

- Le **prix du billet** annulé est remboursé sur le moyen de paiement utilisé.
- **Les frais de service ne sont pas remboursés.**
- Les billets gratuits n'ont rien à rembourser ; ils passent simplement à *Annulé*.
- Si vous avez acheté plusieurs billets en un seul paiement, chaque billet annulé est remboursé de son propre prix. Les remboursements Paystack sont demandés pour la part du paiement correspondant à chaque billet annulé.

## Combien de temps cela prend

L'annulation **demande** immédiatement le remboursement à Paystack. Votre transaction affiche **Remboursement en attente** jusqu'à ce que Paystack le confirme, puis **Remboursé**. Ensuite, le délai pour le voir apparaître sur votre carte ou votre solde mobile money dépend de votre banque ou de votre réseau : en général quelques jours pour les cartes.

Si la demande échoue (par exemple si Paystack était injoignable), votre billet affiche **Échec du remboursement** avec un bouton **Relancer le remboursement**. L'assistance peut aussi relancer la demande.

## Quand l'organisateur annule un événement

Si un organisateur annule, Abonten, automatiquement :

1. annule tous les billets et toutes les inscriptions de l'événement (les vôtres indiqueront *Annulé par l'organisateur*) ;
2. demande le remboursement du prix de chaque billet payant, dans les mêmes conditions que ci-dessus (les frais de service ne sont pas remboursés) ;
3. vous prévient dans l'application et, pour les billets payants, par e-mail.

Vous n'avez rien à faire. Si un remboursement affiche *Échec du remboursement*, utilisez *Relancer le remboursement* ou contactez l'assistance.

## Réservations dans les lieux

Une demande de réservation peut être annulée depuis l'onglet *Réservations* de votre profil (site web) ou Compte › Réservations (application) à tout moment avant la date prévue. Les réservations sont gratuites ; il n'y a rien à rembourser.

## Les remboursements que nous ne pouvons pas accorder

Abonten ne peut pas rembourser un billet parce que vous avez manqué l'événement, êtes arrivé en retard, ne l'avez pas aimé ou parce que l'événement ne correspondait pas à vos attentes : ces questions se règlent entre vous et l'organisateur, à qui vous pouvez écrire depuis la page de l'événement. Vous pouvez aussi signaler l'événement si vous pensez qu'il était frauduleux ou trompeur.

## Litiges avec votre banque

Contactez-nous avant d'ouvrir un litige (rétrofacturation) auprès de votre banque : la plupart des problèmes se règlent plus vite avec l'assistance. Tant qu'un litige est ouvert, le versement de l'organisateur pour cet événement est bloqué et votre compte peut être suspendu temporairement.
