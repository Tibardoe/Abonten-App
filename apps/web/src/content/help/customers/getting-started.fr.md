# Bien démarrer et se connecter

Abonten Hub fonctionne dans votre navigateur sur abontenhub.com et sous la forme de l'application Abonten sur Android. (Une version iPhone n'est pas encore disponible.) Vous pouvez parcourir les événements et les lieux sans compte ; il vous en faut un pour acheter des billets, envoyer des messages, réserver, laisser un avis ou enregistrer des éléments.

## Trois façons de se connecter

Abonten n'utilise pas de mot de passe. Choisissez la méthode la plus simple pour vous :

| Méthode | Ce qui se passe |
|---|---|
| **Google** | Vous choisissez un compte Google et revenez directement, connecté. |
| **Numéro de téléphone** | Saisissez votre numéro (le Ghana est sélectionné par défaut). Nous vous envoyons un code court par SMS ; saisissez-le et vous êtes connecté. Les codes expirent au bout de 5 minutes, et vous pouvez en demander un nouveau après 60 secondes. |
| **E-mail** | Saisissez votre adresse. Nous vous envoyons un code à 6 chiffres par e-mail ; saisissez-le et vous êtes connecté. |

La première fois que vous vous connectez, nous créons votre compte automatiquement : il n'y a pas d'inscription séparée. Si vous vous connectez plus tard avec une autre méthode qui utilise **la même adresse e-mail vérifiée**, vous arrivez dans le même compte. Un compte créé avec un numéro de téléphone peut ajouter une adresse e-mail plus tard dans Paramètres › Sécurité, ce qui relie les deux.

**Site web :** cliquez sur *Connexion* dans l'en-tête ou le menu latéral. **Application :** l'écran de connexion s'affiche à l'ouverture de l'application, ou depuis Compte › *Connexion*.

## Terminer la configuration de votre compte

**Paramètres › Configuration du compte** liste cinq étapes et explique à quoi sert chacune : votre nom, un nom d'utilisateur que vous choisissez, une photo de profil, une adresse e-mail vérifiée et un numéro de téléphone vérifié. Aucune n'est obligatoire pour utiliser Abonten, à une exception près, au moment où elle compte : **pour payer des billets ou des promotions, votre compte doit avoir une adresse e-mail** (vos billets et votre reçu y sont envoyés) ; le paiement vous en demande donc une si vous n'en avez pas encore. Avoir à la fois une adresse e-mail et un numéro de téléphone vous donne deux façons de vous connecter si vous perdez l'accès à l'une d'elles.

Tant qu'il reste des étapes, une petite carte sur l'Accueil (application) ou sur Explorer (site web) vous le rappelle. Touchez *Pas maintenant* pour la ranger : elle disparaît une semaine, puis un mois, puis trois mois, sur tous vos appareils, et ne revient plus une fois tout terminé.

## Codes d'invitation

Si un ami vous a donné un lien ou un code d'invitation, ouvrez le lien avant de créer votre compte (ou saisissez le code sur l'écran de connexion). Les codes d'invitation ne fonctionnent que pour les nouveaux comptes, pendant leur première semaine. Recevoir un crédit de bienvenue dépend de la disponibilité du programme Abonten Rewards pour vous : voir [Récompenses et Abonten Credit](/help/customers/rewards-and-credit).

## Se repérer

**Site web**

- L'**en-tête** contient la recherche, le lieu que vous explorez et le menu de votre profil.
- Le **menu latéral** (☰) regroupe Créer (pour les organisateurs), Messages, Récompenses, Finances, Travail de terrain (si vous faites partie d'une équipe de terrain Abonten), Paramètres et les liens juridiques.
- **Mes billets** se trouve dans Gérer › Mes billets.

**Application**

- Onglets : **Accueil** (ce qui se passe près de chez vous), **Rechercher**, **Spotlight** (vidéos courtes), **Messages** et **Compte**. Vos billets se trouvent dans **Compte › Mes billets**.
- Le **tiroir** (balayez depuis le bord gauche ou touchez le bouton de menu) reprend les principales destinations et contient les liens juridiques.
- **Compte** regroupe Mes billets, Paramètres, Notifications, Transactions, Portefeuille, Lieux, Récompenses (lorsque le programme est disponible), les outils d'organisateur (dès que vous avez créé quelque chose) et *Aide et assistance*.

## Langue et apparence

Paramètres › Langue propose l'anglais, le français, l'espagnol, l'allemand, le portugais et le twi (le twi est traduit en partie ; ce qui n'est pas encore traduit s'affiche en anglais). Le centre d'aide est disponible dans les mêmes langues, sauf le twi. Paramètres › Apparence permet de choisir clair, sombre ou système. Les deux choix sont mémorisés sur l'appareil où vous les faites, et votre langue sert aussi pour les e-mails et les notifications que nous vous envoyons.

## Se déconnecter

**Site web :** menu latéral › Déconnexion. **Application :** Compte › Déconnexion (cela arrête aussi les notifications push sur cet appareil).

## Un problème de connexion ?

- **Aucun code reçu** : patientez une minute, vérifiez le numéro ou l'adresse saisis, puis utilisez *Renvoyer le code*. Les codes envoyés par e-mail peuvent arriver dans les spams. Les codes expirent au bout de 5 minutes.
- **« Trop de tentatives »** : vous pouvez vous tromper de code cinq fois avant qu'il soit annulé ; demandez-en un nouveau. Le nombre d'envois par heure est également limité pour protéger votre numéro.
- **La connexion avec Google échoue** : réessayez ; si l'échec persiste, utilisez votre numéro de téléphone ou votre adresse e-mail. La même adresse e-mail mène au même compte.
- **« Votre compte est restreint »** : voir [Comptes restreints](/help/account/restricted-accounts).

## Contacter l'assistance

- **Dans l'application ou sur le site web :** ouvrez Messages et choisissez *Contacter l'assistance Abonten* (site web) ou Compte › *Aide et assistance* (application). Les réponses arrivent sous forme de messages et de notifications.
- **Si vous ne pouvez pas vous connecter :** écrivez à **support@abontenhub.com** depuis l'adresse e-mail de votre compte.
- **Horaires :** l'assistance est assurée du lundi au vendredi, de 9 h à 17 h, heure du Ghana (GMT), hors jours fériés. Nous visons une réponse sous deux jours ouvrés ; c'est un objectif, pas une garantie. Abonten ne propose pas d'assistance par téléphone ni 24 h/24.
