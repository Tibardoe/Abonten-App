# Sitio web o aplicación

| Función | Sitio web | Aplicación Android |
|---|---|---|
| Explorar, buscar, mapa, páginas de eventos y lugares | ✓ | ✓ |
| Comprar entradas, registrarse, códigos promocionales, monedero | ✓ | ✓ |
| Entradas con código QR, PDF y recibo | ✓ | ✓ |
| Reservas, reseñas, destacados, favoritos | ✓ | ✓ |
| Mensajes (texto, fotos, archivos) | ✓ | ✓ |
| Notas de voz en los mensajes | — | ✓ |
| Spotlight, Stories y seguir | ✓ | ✓ |
| Abonten Weekly | ✓ | ✓ |
| Notificaciones push | ✓ (si el navegador lo admite) | ✓ |
| Recordatorios de eventos | — | ✓ |
| Herramientas de organizador (crear, editar, códigos promocionales, finanzas, retiros) | ✓ | ✓ |
| Registrar la entrada de asistentes desde la lista | ✓ | ✓ |
| Escanear los códigos QR de las entradas con la cámara | — | ✓ |
| Herramientas para propietarios de lugares (editar, fotos, horario, reservas, reseñas) | ✓ | ✓ |
| Herramientas de los equipos de campo de Abonten | ✓ | — |
| Ajustes: perfil, seguridad, idioma, apariencia, eliminar la cuenta | ✓ | ✓ |
| Páginas legales y este centro de ayuda | ✓ | abre el sitio web |

**iPhone:** todavía no hay versión de la aplicación para iOS. En iPhone puedes usar el sitio web.

**Enlaces:** los enlaces de eventos, lugares e invitaciones (`abontenhub.com/events/…`, `/places/…`, `/invite/…`) se abren directamente en la aplicación en Android si la tienes instalada.
