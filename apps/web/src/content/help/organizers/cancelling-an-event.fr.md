# Annuler un événement

L'annulation est **définitive et ne peut pas être défaite**. Tant qu'aucun billet n'est confirmé, vous pouvez simplement modifier la date ou le lieu ; ensuite, ils sont verrouillés pour protéger les personnes qui ont déjà un billet.

## Comment annuler

Ouvrez l'événement dans Gérer › Événements (site web) ou Organisateur › Événements (application) et choisissez **Annuler l'événement**. Avant que vous confirmiez, la fenêtre de confirmation indique combien de **billets payants**, d'**inscriptions gratuites** et de **participants** sont concernés.

## Ce que fait Abonten quand vous confirmez

1. Il marque l'événement comme **annulé** ; il disparaît des résultats et les ventes s'arrêtent.
2. Il annule tous les billets et toutes les inscriptions ; les participants voient *Annulé par l'organisateur*.
3. Il **demande à Paystack le remboursement du prix de chaque billet payant**. Les acheteurs récupèrent le prix de leur billet sur le moyen de paiement utilisé ; les frais de service d'Abonten ne leur sont pas remboursés.
4. Il prévient chaque participant dans l'application, et les participants payants par e-mail. L'avis indique que le remboursement est *en cours de traitement* ; Paystack le confirme ensuite.
5. Il annule dans votre registre les gains en attente liés à ces billets.

Si une demande de remboursement échoue (par exemple si le prestataire de paiement était indisponible), l'acheteur voit une option *Relancer le remboursement*, et l'équipe financière d'Abonten peut relancer la demande.

## Votre argent

Les gains d'un événement annulé sont annulés. Si une partie d'un versement précédent les incluait déjà, votre solde disponible peut devenir négatif ; il est alors compensé sur vos gains futurs.

## Promotions

Une promotion payante sur un événement annulé n'est pas remboursée.

## Déplacer l'événement à une autre date

Abonten n'a pas d'état « reporté ». Tant qu'aucun billet n'est confirmé, modifiez les dates de l'événement. Une fois des billets confirmés, la date et le lieu ne peuvent plus changer : annulez l'événement (les acheteurs récupèrent le prix du billet), créez un nouvel événement à la nouvelle date et indiquez où le trouver dans la description de l'événement annulé.

## Communiquer

Utilisez **Message** depuis l'événement pour répondre aux participants qui vous ont écrit, et indiquez la raison dans la description de l'événement avant d'annuler, pour que les personnes qui le consultent comprennent ce qui s'est passé.
