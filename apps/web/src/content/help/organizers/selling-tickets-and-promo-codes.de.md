# Tickets verkaufen, Promo-Codes und Promoter-Provision

## So läuft ein Verkauf ab

1. Ein Käufer wählt Tickets; diese werden während des Bezahlens **30 Minuten lang reserviert**. Reservierte, aber nicht bezahlte Tickets gehen nach Ablauf der Reservierung zurück in den Bestand.
2. Die Zahlung wird über Paystack eingezogen und von Abonten geprüft.
3. Die Tickets werden für den Käufer ausgestellt, und **100 % deines Ticketpreises** werden für dich als ausstehende Einnahme verbucht.
4. Der Käufer erhält seine Tickets in der App und per E-Mail.

Käufer können höchstens 50 Tickets einer Art und 100 Tickets pro Bestellung reservieren, und pro Event jeweils nur eine Bestellung.

## Kapazität und Ticketmengen

Beides ist optional und wirkt zusammen:

- Die **Kapazität** (Grunddaten) ist die Höchstzahl an Personen für das gesamte Event.
- Die **Menge** einer Ticketart gibt an, wie viele Tickets dieser Art verkauft werden können.
- Ohne Kapazität kannst du beliebige Mengen festlegen oder gar keine.
- Mit Kapazität dürfen die festgelegten Mengen zusammen nicht darüber liegen – du siehst einen Hinweis (zum Beispiel 110 Tickets insgesamt bei einer Kapazität von 100) und kannst erst speichern, wenn es passt.
- Ticketarten ohne Menge **teilen sich, was von der Kapazität übrig ist**, nachdem die festgelegten Mengen abgezogen sind. Bei Kapazität 100, Standard = 60 und VIP leer werden höchstens 60 Standard verkauft und über alle Arten ohne Menge hinweg höchstens 40 weitere. Lässt du alle Mengen leer, werden alle 100 Plätze geteilt.
- Der Verkauf einer Art endet, wenn ihre eigene Menge aufgebraucht ist, und für alle geteilten Arten, wenn die geteilten Plätze weg sind. Reservierte Tickets zählen mit, bis ihre 30-minütige Reservierung abläuft.

## Promo-Codes

Öffne dein Event › **Promo-Codes** (Website: Verwalten › Events › Event; App: Veranstalter › Events › Event › Promo-Codes).

- **Kostenlose Events haben keine Promo-Codes.** Ein Code senkt einen Ticketpreis, und ein kostenloses Ticket hat keinen; deshalb gibt es die Option bei kostenlosen Events nicht. Machst du ein kostenpflichtiges Event kostenlos, werden seine Codes entfernt: Nie genutzte Codes werden gelöscht, genutzte deaktiviert (ihr Verlauf bleibt erhalten). Mach das Event wieder kostenpflichtig, um Codes hinzuzufügen.

- Ein Code gewährt einen **prozentualen Rabatt** auf den Ticketpreis, nur für dein Event.
- Du kannst festlegen, wie oft er genutzt werden darf, und ihn später bearbeiten oder löschen; das Löschen wirkt sich nicht auf bereits damit gekaufte Tickets aus.
- Käufer geben den Code an der Kasse ein; der Rabatt wird vor dem Bezahlen angezeigt. Abonten begrenzt, wie schnell ein Konto Codes ausprobieren kann, damit sie nicht erraten werden.
- In deinen Statistiken siehst du, wie viele Verkäufe jeden Code genutzt haben.

## Promoter-Provision

Wo die Funktion verfügbar ist, kannst du Personen, die dir Käufer bringen, eine **Provision von 1 % bis 30 % des Ticketpreises** anbieten, festgelegt pro Event unter **Promoter-Provision**. Kauft jemand über den Teilen-Link eines Promoters, wird die Provision an den Promoter als Abonten Credit ausgezahlt, sobald der Verkauf abgerechnet ist, und dir im selben Moment als Abzug in deinem Kontobuch **berechnet**. Erstattungen, Stornierungen und Rückbuchungen machen sie rückgängig. Für künftige Verkäufe kannst du sie jederzeit abschalten.

## Statistiken

Öffne dein Event › **Statistiken** (Website: `?tab=insights`; App: die Übersicht des Events): Verkäufe im Zeitverlauf, verkaufte Tickets nach Art, Nutzung von Promo-Codes, wiederkehrende Teilnehmer, Einnahmen und die Teilnehmerliste. Das **Dashboard** (Website: Verwalten › Dashboard; App: Veranstalter-Startseite) fasst alle deine veröffentlichten Events zusammen: Bruttoumsatz, verkaufte Tickets, aktive Events, kommende Events, Dinge, die deine Aufmerksamkeit brauchen, und letzte Aktivitäten.

## Dein Event teilen

Nutze **Teilen** auf der Event-Seite. Läuft das Programm Abonten Rewards, enthalten Teilen-Links einen Empfehlungscode, damit die teilende Person für Verkäufe, die sie bringt, belohnt werden kann.

## Ausverkauft und Wartelisten

Der Verkauf endet automatisch, wenn die Menge einer Ticketart oder die Kapazität des Events erreicht ist. Abonten hat keine Warteliste. Mengen und Kapazität lassen sich über **Bearbeiten** nur erhöhen, bis das erste Ticket bestätigt ist; danach sind sie gesperrt, genau wie die Ticketarten selbst.
