# Dein Event bewerben

## Was eine Promotion bewirkt

Ein beworbenes Event wird **hervorgehoben**: Es erscheint im Karussell „Hervorgehoben“ auf der Start- und der Entdecken-Seite für deine Gegend und ist als beworben gekennzeichnet. Über diesen hervorgehobenen Platz hinaus ändert eine Promotion nichts an der Reihenfolge in der Suche.

## Eine Promotion kaufen

1. Öffne dein Event › **Bewerben** (Website: Verwalten › Events › Event; App: Veranstalter › Events › Event › Bewerben).
2. Wähle eine Stufe – die Laufzeiten reichen von 24 Stunden bis zu einem Monat; jede Stufe zeigt ihren Preis, bevor du bezahlst.
3. Bezahle mit Karte, Mobile Money oder einer gespeicherten Methode. Läuft das Programm Abonten Rewards und hast du Promotion-Guthaben, zeigt die Kasse, wie viel Guthaben angerechnet wird und wie viel noch in Geld zu zahlen ist.
4. Die Promotion **beginnt, sobald die Zahlung bestätigt ist**, und läuft für die gekaufte Dauer. Deine aktiven Promotions erscheinen beim Event und in deinem Transaktionsverlauf.

## Regeln

- Promotions werden nach dem Start nicht erstattet, außer wenn Abonten sie nicht erbringen konnte.
- Ein Eintrag, der wegen Regelverstößen **eingeschränkt**, **ausgeblendet** oder **entfernt** wurde, kann nicht beworben werden, und eine Promotion für einen später entfernten Eintrag wird nicht erstattet.
- Eine Promotion für ein Event, das du absagst, wird nicht erstattet.

## Promoter-Provision (die andere Art der Werbung)

Unabhängig von der bezahlten Hervorhebung kannst du andere dein Event gegen einen Anteil an jedem Verkauf bewerben lassen – siehe [Tickets verkaufen, Promo-Codes und Promoter-Provision](/help/organizers/selling-tickets-and-promo-codes).
