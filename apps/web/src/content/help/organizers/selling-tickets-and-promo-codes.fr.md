# Vendre des billets, codes promo et commission des promoteurs

## Comment se passe une vente

1. Un acheteur choisit des billets ; ils sont **réservés pendant 30 minutes** pendant qu'il paie. Les billets réservés mais non payés reviennent dans le stock à l'expiration de la réservation.
2. Le paiement est encaissé par Paystack et vérifié par Abonten.
3. Les billets sont émis pour l'acheteur, et **100 % du prix de votre billet** est enregistré comme gain en attente pour vous.
4. L'acheteur reçoit ses billets dans l'application et par e-mail.

Un acheteur peut réserver au plus 50 billets d'un même type et 100 billets par commande, et une seule commande par événement à la fois.

## Capacité et quantités de billets

Les deux sont facultatives et fonctionnent ensemble :

- La **capacité** (Informations de base) est le nombre maximal de personnes que l'événement peut accueillir.
- La **quantité** d'un type de billet est le nombre de billets de ce type qui peuvent être vendus.
- Sans capacité, fixez les quantités que vous voulez, ou aucune.
- Avec une capacité, le total des quantités fixées ne doit pas la dépasser : un message vous l'indique (par exemple un total de 110 billets pour une capacité de 100) et vous ne pouvez pas enregistrer tant que cela ne tient pas.
- Les types de billets laissés sans quantité **se partagent ce qui reste de la capacité** après les quantités fixées. Avec une capacité de 100, Standard = 60 et VIP laissé vide, on peut vendre au plus 60 Standard et, pour l'ensemble des types sans quantité, au plus 40 de plus. Laissez toutes les quantités vides et les 100 places sont partagées.
- Les ventes s'arrêtent pour un type quand sa propre quantité est épuisée, et pour tous les types partagés quand les places partagées sont parties. Les billets réservés comptent jusqu'à l'expiration de leur réservation de 30 minutes.

## Codes promo

Ouvrez votre événement › **Codes promo** (site web : Gérer › Événements › l'événement ; application : Organisateur › Événements › l'événement › Codes promo).

- **Les événements gratuits n'ont pas de codes promo.** Un code réduit le prix d'un billet, et un billet gratuit n'en a pas ; l'option n'est donc pas proposée pour un événement gratuit. Rendre gratuit un événement payant retire ses codes : les codes jamais utilisés sont supprimés et ceux déjà utilisés sont désactivés (leur historique est conservé). Rendez l'événement de nouveau payant pour ajouter des codes.

- Un code applique une **réduction en pourcentage** sur le prix du billet, pour votre événement uniquement.
- Vous pouvez fixer combien de fois il peut être utilisé, et le modifier ou le supprimer plus tard ; le supprimer n'a aucun effet sur les billets déjà achetés avec.
- Les acheteurs saisissent le code au moment du paiement ; la réduction s'affiche avant qu'ils paient. Abonten limite la vitesse à laquelle un compte peut essayer des codes, pour empêcher de les deviner.
- Vos statistiques indiquent combien de ventes ont utilisé chaque code.

## Commission des promoteurs

Là où la fonctionnalité est disponible, vous pouvez offrir aux personnes qui vous amènent des acheteurs une **commission de 1 % à 30 % du prix du billet**, réglée pour chaque événement dans **Commission des promoteurs**. Quand quelqu'un achète via le lien de partage d'un promoteur, la commission est versée au promoteur en Abonten Credit une fois la vente réglée, et **vous est facturée** au même moment sous forme de déduction dans votre registre. Les remboursements, les annulations et les rétrofacturations l'annulent. Vous pouvez la désactiver à tout moment pour les ventes futures.

## Statistiques

Ouvrez votre événement › **Statistiques** (site web : `?tab=insights` ; application : la vue d'ensemble de l'événement) : ventes dans le temps, billets vendus par type, utilisation des codes promo, participants fidèles, recettes et liste des participants. Le **Tableau de bord** (site web : Gérer › Tableau de bord ; application : accueil Organisateur) regroupe tous vos événements publiés : ventes brutes, billets vendus, événements actifs, événements à venir, points qui demandent votre attention et activité récente.

## Partager votre événement

Utilisez **Partager** sur la page de l'événement. Quand le programme Abonten Rewards est ouvert, les liens de partage contiennent un code de parrainage pour que la personne qui partage puisse être récompensée des ventes qu'elle apporte.

## Complet et listes d'attente

Les ventes s'arrêtent automatiquement quand la quantité d'un type de billet est atteinte, ou quand la capacité de l'événement l'est. Abonten n'a pas de liste d'attente. Les quantités et la capacité ne peuvent être augmentées depuis **Modifier** que jusqu'à la confirmation du premier billet ; ensuite, elles sont verrouillées, comme les types de billets eux-mêmes.
