# Réservations, avis et messages

## Demandes de réservation

Les clients peuvent envoyer une **demande de réservation** depuis votre page : un service facultatif, une date et une heure, le nombre de personnes et une note. Vous êtes prévenu dans l'application.

Ouvrez votre lieu › **Réservations** (site web : Gérer › Lieux › le lieu ; application : Organisateur › Lieux › le lieu › Réservations) pour voir les demandes en attente, acceptées, refusées et annulées. **Acceptez** ou **refusez** chaque demande en attente ; le client est prévenu dans les deux cas. Les clients peuvent annuler leur propre demande ; vous le voyez aussi.

Les réservations sont gratuites et non payées ; tout acompte ou arrangement de paiement se règle entre vous et le client, en dehors d'Abonten.

## Avis

Tout utilisateur connecté peut donner son avis sur votre lieu (un avis chacun). Les avis s'affichent sur votre page et sur le profil de leur auteur, et votre note globale est leur moyenne.

Dans votre lieu › **Avis**, vous pouvez publier **une réponse publique** par avis, la modifier ou la retirer. Vous ne pouvez pas retirer l'avis d'un client. Si un avis est faux, injurieux ou enfreint les règles d'une autre façon, **signalez-le** : les modérateurs d'Abonten peuvent le masquer ou le retirer. Les avis positifs coordonnés ou payés pour votre propre lieu sont contraires aux Conditions.

## Messages

Les clients peuvent écrire à votre lieu depuis sa page. Les conversations apparaissent dans **Messages**, avec un filtre *professionnel* pour les propriétaires et les organisateurs. Répondez avec du texte, des photos, des fichiers et (dans l'application) des messages vocaux. Bloquer un participant arrête ses messages à votre lieu.

## Notifications

Vous recevez une notification dans Abonten (et une notification push dans l'application) pour chaque nouvelle demande de réservation, annulation, avis et message.
