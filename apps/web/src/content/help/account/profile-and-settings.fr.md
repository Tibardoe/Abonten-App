# Votre profil et vos paramètres

## Votre profil public

Votre profil (site web : `/user/<nom d'utilisateur>` ; application : Compte › votre nom) affiche votre photo, votre nom, votre nom d'utilisateur, votre bio et votre site web, ainsi que des onglets pour les événements que vous avez publiés, les lieux qui vous appartiennent, vos avis et, visibles par vous seul, vos favoris et vos réservations.

## Modifier votre profil

**Paramètres › Modifier le profil** (site web et application) : nom, nom d'utilisateur, bio, site web et photo. La photo est recadrée dans l'application ou le navigateur puis envoyée directement à notre hébergeur d'images ; une barre de progression suit l'envoi. Chaque nom d'utilisateur doit être unique. **Paramètres › Configuration du compte** liste les cinq étapes d'un compte complet (nom, nom d'utilisateur choisi, photo, adresse e-mail vérifiée, téléphone vérifié) ; une petite carte de rappel s'affiche tant qu'il reste des étapes, et *Pas maintenant* la range pour un moment.

## Numéro de téléphone et adresse e-mail

**Paramètres › Sécurité** :

- **Téléphone** : ajoutez ou changez votre numéro. Nous envoyons un code par SMS au **nouveau** numéro ; saisissez-le pour confirmer. Le code expire au bout de 5 minutes.
- **E-mail** : ajoutez ou changez votre adresse. Nous envoyons un code à 6 chiffres à la **nouvelle** adresse ; saisissez-le pour confirmer. Un compte créé avec un téléphone qui ajoute une adresse e-mail vérifiée peut ensuite aussi se connecter avec Google ou avec un code par e-mail.

Dans les deux cas, vous restez connecté.

## Être connecté sur plusieurs appareils

Vous restez connecté sur chaque téléphone, tablette et navigateur jusqu'à ce que vous vous y déconnectiez. Vous déconnecter sur un appareil ne vous déconnecte nulle part ailleurs.

**Paramètres › Sécurité › Se déconnecter des autres appareils** vous déconnecte partout sauf sur l'appareil que vous utilisez, et ces appareils ne reçoivent plus vos notifications. Utilisez-le si vous perdez ou vendez un téléphone, ou si vous vous êtes connecté sur celui de quelqu'un d'autre.

## Langue

**Paramètres › Langue** : anglais, français, espagnol, allemand, portugais, twi (traduit en partie). Le choix est enregistré sur cet appareil (dans un cookie sur le site web) et, quand vous êtes connecté, utilisé pour les e-mails et les notifications que nous vous envoyons.

## Apparence

**Paramètres › Apparence** : clair, sombre ou selon le système.

## Comptes bloqués

Pour bloquer quelqu'un, ouvrez son profil : sur le site web, choisissez **Bloquer** à côté de **Signaler** ; dans l'application, touchez **⋯** en haut, puis **Bloquer**. Vous pouvez aussi bloquer quelqu'un depuis l'un de ses avis ou depuis une conversation. Cette personne ne peut plus vous écrire, ses avis, ses Spotlights et ses commentaires vous sont masqués, et tout abonnement entre vous prend fin. Elle n'en est pas informée.

**Paramètres › Comptes bloqués** liste les personnes que vous avez bloquées et vous permet de les débloquer.

## Portefeuille et comptes de versement

Les moyens de paiement enregistrés se trouvent dans **Portefeuille**. Les comptes de versement des organisateurs se trouvent dans **Finances › Comptes de versement** : voir [Finances, versements et règlement](/help/organizers/finance-payouts-and-settlement).

## Supprimer votre compte

**Paramètres › Sécurité › Supprimer le compte**. Voir [Supprimer votre compte](/help/account/deleting-your-account) pour savoir exactement ce qui est supprimé et ce qui est conservé.
