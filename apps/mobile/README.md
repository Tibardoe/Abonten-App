# @abonten/mobile

Expo (SDK 57) / Expo Router app. Part of the Abonten monorepo.

## Running

**Run Expo from this directory, not the repo root.** The repo root has no
Expo entry point — `npx expo start` there fails with
`Unable to resolve "../../App" from node_modules/expo/AppEntry.js`.

```bash
# from apps/mobile
npx expo start          # then press i / a / w
npx expo start --ios
npx expo start --android
```

Or from the repo root, via the workspace scripts:

```bash
npm run mobile          # expo start
npm run mobile:ios
npm run mobile:android
```

## Environment

Copy `.env.example` to `.env` and fill in the PUBLIC values
(`EXPO_PUBLIC_*` is inlined into the bundle — never put a secret here):

- `EXPO_PUBLIC_SUPABASE_URL`, `EXPO_PUBLIC_SUPABASE_ANON_KEY` — same Supabase
  project as the web app.
- `EXPO_PUBLIC_API_BASE_URL` — origin of the web deployment that serves
  `/api/mobile/**`.

For Google sign-in, add `abonten://auth/callback` to the Supabase Auth
redirect allow list.

## Notes

- `web.output` is `single` (SPA). Web is a dev convenience only — the app
  targets iOS/Android. Static web export is not supported (native-only
  modules like `expo-secure-store` break server prerendering).
- Native `ios/`/`android/` dirs are generated by `expo prebuild` and
  gitignored (continuous native generation). EAS Build/Update: Phase 6.
- Metro is configured for the npm-workspaces monorepo in `metro.config.js`.
