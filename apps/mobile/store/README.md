# Store listings

The words and declarations Abonten gives the App Store and Google Play. The
full account (what each answer means, the pictures, countries, what to do
before release) is in [docs/deployment/store-listings.md](../../../docs/deployment/store-listings.md).

| File | What it is |
|---|---|
| `apple/listing.en-GB.json` | App Store name, subtitle, description, keywords, links, categories |
| `apple/privacy.json` | App Store "App Privacy" answers (`asc web privacy plan` / `apply` / `publish`) |
| `google-play/listing.en-GB.json` | Google Play title, short and full description, category, contact |
| `google-play/data-safety.csv` | Google Play Data safety answers (Play Console › Data safety › Import from CSV) |

The two privacy files say the same thing as the Privacy Policy
(`apps/web/src/content/legal/privacy-policy.md` §2–3). Change all three
together.

Not here, on purpose: the reviewer sign-in code and notes (they live only in
App Store Connect, the Play Console and the web project's environment), and
the screenshots (`Desktop\Abonten-Brand\08-store-listing`, generated by
`Abonten-Brand\src\store\render.cjs`).
