# User journey maps

Each map lists the stages, what the user does, where (W = web, A = Android app, C = admin console), what the system does, and where the detail lives. Failure points link to troubleshooting or runbooks.

| Journey | File |
|---|---|
| Customer: discovery → account → event/place → checkout → payment → ticket → attendance → review → rewards | [customer.md](customer.md) |
| Organizer: sign-up → event creation → publication → promotion → sales → event day → settlement → payout | [organizer.md](organizer.md) |
| Place owner: sign-up → claim or create → verification → management → discovery → bookings and reviews | [place-owner.md](place-owner.md) |
| Field agent: invitation → login → assignment → onboarding → verification → sweep → payout → escalation | [field-agent.md](field-agent.md) |
| Admin: login → monitoring → moderation → support → finance → security → reporting → audit | [admin.md](admin.md) |
